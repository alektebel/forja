## Purpose

These reference implementations demonstrate how each stage's functions should behave. They are used by:

- `verify_cws.py` — to validate that the stage checks pass when solutions are loaded
- `mutate_cws.py` — as the base for mutation testing (20+ mutations, all must be killed)

## Note

These are reference implementations for learning purposes. The course is designed for you to write your own implementations from scratch, using the world modules as data sources.
